## 原因与改动

原请求停在主 Agent 委派阶段：模型给日期范围附加了 description/tz 等字段，或将指标写成字符串数组。直接协议校验抛异常，Web 将请求标为 interrupted；重试相同检查点仍收到相同参数，因此重复失败。

- 给模型暴露明确的指标和日期对象 schema，区分本期和基期，保留完整原问题。
- 委派参数不合法时，向模型反馈字段错误，最多修正两次。仍失败则保存失败报告并结束本轮，不再抛出未处理的 HTTP 500。
- 服务端提前提供实际表字段，避免子 Agent 通过业务 SQL 枚举全库结构。Text2SQL 同时接收预期输出列单位。
- 默认模型调用上限从 12 调为 20；累计预算仍受限。预算耗尽使用专门异常贯穿 Text2SQL，避免被错误转为“评分不可用”的人工审核。终止时把遗留 running 证据标为失败。
- 模型完成工具后若直接输出文本、未提交报告，允许一次受同一累计预算约束的报告补交。仍未提交则明确失败，绝不把草稿当报告。
